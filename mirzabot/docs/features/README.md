۲. **موتور فروش:** F04 (Trial) ← F03 (کوپن) ← F22 (کد گیفت) ← F01 (تمدید خودکار).
۳. **نگهداشت کاربر:** F07 (تیکت) ← F09 (اعلان چندسطحی) ← F10 (راهنمای نصب).
۴. **رشد:** F19 (دعوت دوطرفه) ← F20 (پست خودکار) ← F28 (پیگیری Trial).
۵. **زیرساخت:** F12 (انجام شد) ← F16 (پنل جدید) ← F17/F18 (بار/فیل‌اوور) ← F29.
۶. **ادمین:** F11 (انجام شد) ← F13 (RBAC) ← F14 (خروجی اکسل) ← F33 ← F35.

## وابستگی‌های بحرانی

- هر قابلیتی که موجودی (`Balance`) را تغییر می‌دهد **فقط** از طریق `creditBalance()` / `debitBalanceIfSufficient()` / `settleOrderOnce()` (که در `function.php` موجودند) پیاده شود — هرگز read-then-write مستقیم.
- هر کرون جدید باید الگوی `cronbot/*` را رعایت کند (نصب‌کننده خودش `mirza_cron_lock` را تزریق می‌کند؛ `test_cron.sh` این را چک می‌کند).
- هر اندپوینت API جدید باید `requireApiToken()` یا `requireApiTokenOrAdminSession()` از `api/utils.php` را صدا بزند.
- کلیدهای زبان جدید باید به هر ۴ فایل `lang/{fa,en,ru,zh}.php` با ساختار یکسان اضافه شوند (هم‌ترازی placeholder ها).
